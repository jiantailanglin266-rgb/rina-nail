## 撮影のコツ（スマートフォンで十分です）

- **明るい窓際で、影が出ない向き**に。天井の照明だけだと色がくすみます
- **背景は無地**に。白い紙やタオルを敷くだけで見違えます
- 爪にピントを合わせ、**指全体ではなく手元のアップ**で
- **横位置（スマホを横に倒して）**で撮ると、ギャラリーの 4:3 にそのまま収まります
- 加工は明るさの調整程度に。色を変えすぎると実物と違って見えます

## 置き方A：フォルダごと渡して自動で振り分ける（おすすめ）

**リサイズもトリミングもファイル名も、こちらで自動処理します。**
撮った写真をフォルダにまとめて渡していただくだけで構いません。

```bash
npm run photos -- <写真フォルダのパス>          # 変換して public/images/ へ書き出す
npm run photos -- <写真フォルダのパス> --dry    # 書き込まず、割り当てだけ確認する
```

やっていること（`scripts/prepare-photos.mjs`）

- 上の表のファイル名・寸法へ**自動で変換**します
- 切り抜き位置は中央固定ではなく、**被写体が最も密な領域を残す**方式です
  （ネイル写真は指先が画面の端に寄りがちで、中央で切ると爪が欠けるため）
- スマホ撮影の**向き情報（Exif）を反映**するので、横倒しになりません
- **元画像より大きく引き伸ばしません**（粗くなるため。該当した写真は警告に出ます）
- **余った写真は自動でマーキーへ**回ります

### 振り分けのルール

1. ファイル名に手がかり語が入っていれば、その枠へ
   （`hero` / `owner` / `salon` / `simple` / `office` / `nuance` / `glitter` /
   `gorgeous` / `seasonal` / `mens` / `marquee`。日本語も可：`サロン` `オフィス` など）
2. 手がかり語が無ければ、**横長の写真はギャラリー枠、縦長の写真はオーナー枠**へ順に充当
3. それでも余ったものは全部マーキーへ（`marquee/01.jpg`, `02.jpg` …）

つまり **`hero-`, `owner-`, `salon-` だけ名前を付けておけば、あとは何も考えずに放り込んで大丈夫です。**

### HEIC（iPhoneの標準形式）について

そのままでは読み込めません。iPhoneから送る場合は、
**設定 → カメラ → フォーマット → 「互換性優先」** にしてから撮るか、
共有時に「JPEGに変換」を選んでください。読めなかったファイルは実行結果に一覧で出ます。

## 置き方B：1枚ずつ自分で差し替える

- **ファイル名は上の表と完全に同じにしてください**（大文字小文字も区別されます）
- 形式は JPEG。1枚あたり **300KB以下**が目安です
- 比率が違う写真を入れると、**中央を基準に切り取られて**表示されます。
  上下や左右が切れて困る場合は、事前に表の比率でトリミングしてください

手順

1. パソコンで GitHub のリポジトリを開く
2. 該当フォルダを開き、「Add file」→「Upload files」
3. 同じ名前のファイルをドラッグ＆ドロップ（上書きになります）
4. 「Commit changes」

その後、サイトを再デプロイすると反映されます。

### ギャラリーを 4:3 横位置にした理由

いただいた作例写真は**すべて 16:9 の横位置**で撮られていました。

（`src/data/gallery.ts` の `W` / `H`）。
