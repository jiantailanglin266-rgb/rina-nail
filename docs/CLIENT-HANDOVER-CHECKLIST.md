# 引き渡しチェックリスト（ネット予約）

サイト側の実装は完了しています。以下を上から順に進めてください。
詳しい手順は `docs/GOOGLE-APPOINTMENT-SETUP.md` にあります。

## Googleアカウントの準備

- [ ] 店舗用のGoogleアカウントを用意した（個人用との共用を避ける）
- [ ] **2段階認証を有効にした**
- [ ] パスワードを制作者に共有していない

## 予約スケジュールの作成

- [ ] Googleカレンダーで予約スケジュールを作成した
- [ ] 予約枠のタイトルを設定した（例: ネイル施術予約）
- [ ] 施術時間を設定した（90分 または 120分）
- [ ] 受付できる曜日と時間を設定した
- [ ] 定休日（土・日・祝）を受付対象から外した
- [ ] 最終受付を終了時刻の2時間前までにした
- [ ] 予約受付期間を設定した（推奨: 60日先まで）
- [ ] 直前予約の締切を設定した（推奨: 3時間前まで）
- [ ] 予約フォームの質問項目を設定した（希望メニュー・オフの有無など）
- [ ] 店舗住所または来店方法を設定した

## サイトへの接続

- [ ] 予約ページURLを取得した
- [ ] 通常のカレンダーURLではなく、**予約スケジュールのURL**であることを確認した
- [ ] `NEXT_PUBLIC_GOOGLE_BOOKING_URL` を GitHub の Variables に設定した
- [ ] 本番サイトを再デプロイした

## 動作確認

- [ ] 予約ページでカレンダーが表示された
- [ ] **スマートフォンで予約画面を操作できた**（横にはみ出していない）
- [ ] テスト予約を実施した
- [ ] 予約通知メールが届いた
- [ ] **Googleカレンダーに予定が追加された**
- [ ] スマートフォンに通知が届いた
- [ ] **予約済みの時間が再度選択できないことを確認した**
- [ ] 予約の変更・キャンセル方法を確認した
- [ ] テスト予約を削除した

## 運用開始後

- [ ] 予約を受けたくない時間のブロック方法を理解した（カレンダーに予定を入れるだけ）
- [ ] 臨時休業の登録方法を理解した（終日の予定を入れる）
- [ ] Googleカレンダーアプリの通知をオンにした
- [ ] Gmailアプリの通知をオンにした
