# Googleカレンダー「予約スケジュール」の設定手順

サイト側の実装は完了しています。**あとはGoogleカレンダーで予約ページを作り、
そのURLを設定するだけ**で予約受付が始まります。コードの修正は不要です。

> Googleの画面名や項目は変更されることがあります。
> ここでは「どこで何を決めるか」を書いています。画面上の文言が違う場合は、
> 意味の近い項目を選んでください。

---

## 前提

- **店舗用のGoogleアカウント**を使ってください（個人用との共用は避ける）
- 予約スケジュールは、Google個人アカウントの無料範囲で **1つ** 作成できます
- 有料プラン（Google Workspace）なら複数作成や高度な設定が可能です

## 手順

### 1. 予約スケジュールを作成する

1. パソコンで [Googleカレンダー](https://calendar.google.com/) を開く
2. 「作成」→ **予約スケジュール**（Appointment schedule）
3. 見つからない場合は、カレンダー画面上部の切り替えから探してください

### 2. 予約枠の内容を決める

無料版では予約枠を1種類しか作れないため、**共通の枠**として設定します。

| 項目 | 推奨 |
|---|---|
| タイトル | `ネイル施術予約` |
| 所要時間 | **90分** または **120分** |
| 予約の間隔 | 30分 |
| 場所 | 三重県四日市市平尾町3082-5（または「来店」） |

> メニューごとに時間を変えることは無料版ではできません。
> **長めの枠（120分）**にしておき、実際の施術時間は当日調整するのが安全です。
> 短い枠にすると、時間が足りない予約が入ってしまいます。

### 3. 受付できる曜日と時間を設定する

現在のサイト表記に合わせてください。

| 曜日 | 営業時間 |
|---|---|
| 月・火・木・金 | 10:00〜18:00 |
| 水 | 10:00〜16:00 |
| 土・日・祝 | 定休（受付しない） |

**施術の後片付けを考えて、最終受付は終了時刻の2時間前までにしてください。**
（例: 18:00終了なら最終受付16:00）

### 4. 受付の期間と締切を設定する

| 項目 | 推奨 |
|---|---|
| 何日先まで受け付けるか | 60日 |
| 直前予約の締切 | **3時間前まで** |
| 予約後の変更受付 | 有効にする |

### 5. 予約者に入力してもらう項目を設定する

Googleの予約フォームに「カスタムの質問」を追加できます。
**この項目はGoogleカレンダー側でのみ設定でき、サイトのコードからは変更できません。**

追加を推奨する質問:

| 質問 | 形式 | 必須 |
|---|---|---|
| 希望メニュー | 記述式 または 選択式 | ✅ |
| オフの有無 | 選択式（なし／当店で施術／他店で施術） | ✅ |
| 初回来店か再来店か | 選択式 | 任意 |
| 希望デザイン | 記述式 | 任意 |
| 連絡事項 | 記述式 | 任意 |

**希望メニューの選択肢**（選択式にできる場合）:
ワンカラー／グラデーション／フレンチ／定額デザイン／持ち込みデザイン／
フットネイル／ネイルケア／オフのみ／その他相談

### 6. 予約ページを公開してURLを取得する

1. 設定を保存する
2. **「予約ページを開く」** または **「共有可能なリンクを取得」** を選ぶ
3. 表示されたURLをコピーする

URLは次のどちらかの形です。どちらでも構いません。

```
https://calendar.google.com/calendar/appointments/schedules/AcZssZ...
https://calendar.app.google/xxxxxxxx
```

> ⚠️ **これは通常のカレンダーURLではありません。**
> `calendar.google.com/calendar/u/0/r` のようなURLは使えません。
> 予約スケジュールの設定画面から取得したURLを使ってください。
> また、URLの末尾に余計なパラメータを足さないでください。

### 7. サイトに設定する

GitHubリポジトリの **Settings → Secrets and variables → Actions → Variables** で追加します。

| 名前 | 値 |
|---|---|
| `NEXT_PUBLIC_GOOGLE_BOOKING_URL` | 手順6でコピーしたURL |

保存したら、GitHub Actions の `pages.yml` を実行して再デプロイしてください。
**これだけで予約画面が有効になります。** コードの変更は不要です。

ローカルで試す場合は `.env.local` に同じ変数を書いてください。

### 8. 動作を確認する

1. 予約ページ（`/ja/booking/`）を開き、カレンダーが表示されるか
2. スマートフォンで操作しやすいか（枠から飛び出していないか）
3. テスト予約をしてみる
4. 予約完了メールが届くか
5. **Googleカレンダーに予定が追加されるか**
6. スマートフォンに通知が届くか
7. **同じ時間をもう一度予約できないこと**（重複しないこと）

テスト予約は、確認後にGoogleカレンダーから削除してください。

## 運営者の日常的な使い方

専用の管理画面はありません。**Googleカレンダーアプリと Gmail だけ**です。

### 予約を確認する

Googleカレンダーアプリを開くと、予約が予定として入っています。
タップすると、予約者名・入力してもらった内容が表示されます。

### 予約者へ連絡する

予約通知メール（Gmail）に予約者のメールアドレスが載っています。
そこから返信できます。電話番号を質問項目に入れていれば、
メール内の番号をタップして発信できます。

### 予約を受けたくない時間をブロックする

**Googleカレンダーに普通の予定を入れるだけです。**
予約スケジュールと重なる時間は、自動的に予約できなくなります。

```
例) 14:00-16:00「外出」
```

### 臨時休業日を登録する

その日に **終日の予定**（例:「休み」）を入れてください。
1日まるごと予約できなくなります。

### 営業時間を変更する

Googleカレンダーの予約スケジュールを開き、受付時間を編集します。
**サイト側の表示（営業時間の記載）も変える場合は、
`src/data/hours.ts` の更新が必要です。** 制作者にご依頼ください。

### 予約受付期間を変更する

同じく予約スケジュールの設定画面で、「何日先まで」を変更します。

### 予約ページURLを確認する／再取得する

予約スケジュールの設定画面から、いつでも同じURLを取得できます。
URLが変わった場合は、手順7をやり直してください。

### Googleアカウントを守る

- **2段階認証を必ず有効にしてください**（設定 → セキュリティ）
- パスワードを制作者や第三者に共有しないでください
- カレンダー全体を一般公開しないでください（予約ページだけが公開されます）

### スマートフォンへの通知

Googleカレンダーアプリ → 設定 → 通知 で、新しい予定の通知をオンにしてください。
Gmailアプリの通知もオンにしておくと、予約時にすぐ気づけます。

## 無料版でできないこと

| できないこと | 代わりの方法 |
|---|---|
| メニューごとに所要時間を変える | 長めの共通枠にし、希望メニューを質問項目で聞く |
| 予約スケジュールを複数作る | 1つの枠で運用する |
| 確認メールの文面を自由に変える | Googleの定型文のまま運用する |
| 独自のリマインドメール | Googleカレンダーの通知機能を使う |
| 予約者の情報をサイト側に保存 | 保存しません（Google側で管理） |

これらが必要になった場合の選択肢は `docs/archive/README.md` に記載しています。
