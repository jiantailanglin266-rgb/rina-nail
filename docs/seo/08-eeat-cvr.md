## ⑨ E-E-A-T：不足情報の一覧

Google の評価軸である Experience（経験）/ Expertise（専門性）/
Authoritativeness（権威性）/ Trust（信頼性）で棚卸ししました。

### 現状で満たしているもの ✅

| 軸 | 内容 |
|---|---|
| Expertise | フィルインの説明、施術の流れ5工程、メニュー体系 |
| Experience | ネイリスト歴10年の記載、オーナープロフィール |
| Trust | 完全予約制・チェア数/スタッフ数の明示、プライバシーポリシー、利用規約、支払い方法 |
| Trust | 「絶対に傷まない」等の誇大表現を避けている（**これは大きな加点要素です**） |

### 追加すべき新規セクション

**1. お客様の声（`/voice` または about内）**
```
・掲載はご本人の許可を得たもののみ
・イニシャル＋年代＋メニュー名（例: A様 30代 フィルイン）
・写真があれば手元のみ
・最低3件そろってから公開（1件だけだと逆効果）
→ そろい次第 Review スキーマを追加（それまでは絶対に入れない）
```

**2. 衛生管理（about内）**
```
・器具の消毒方法（具体的な薬剤・工程）
・使い捨てにしているもの（ファイル・ウッドスティック等）
・施術前後の手指消毒
・写真つきで説明する
```

**3. 保証・キャンセルポリシー（first-visit内）**
```
保証: 施術後◯日以内の取れ・浮きは無料でお直し（対象外の条件も明記）
キャンセル: ◯日前まで無料 / 前日◯% / 当日◯%
無断キャンセル: 次回予約の取り扱い
```

## ⑩ CVR（予約率）改善

### 現状の導線構造（実測）

| 導線 | 状態 |
|---|---|
| ヘッダー固定CTA | ✅ あり（PC）／モバイルはハンバーガー内 |
| ヒーローCTA | ✅ あり |
| セクション間CTA | ✅ 複数あり |
| モバイル固定下部バー | ✅ あり（2ボタン：クーポン／予約） |
| フッターCTA | ✅ あり |
| **リンク先** | ❌→✅ **全て行き止まりだった（今回修正）** |
| 電話CTA | ❌ 電話番号未設定のため非表示 |
| LINE予約 | ❌ 未実装 |
| Instagram導線 | ❌ URL未設定のため非表示 |

CTAの**配置は十分**です。問題は「リンク先が無いこと」でした。

### 改善提案（効果の大きい順）

**1. 予約URLを設定する【最優先・効果測定不能なほど大きい】**
現状のCVRは構造的に0%です。他の全ての施策の前提。

**2. LINE公式アカウントを予約導線に追加する【★★★】**

*理由:* 予約サイト経由は「アカウント登録」というハードルがあります。
LINEは既にインストール済みで、**「まず質問したい」層を取りこぼしません**。
特に「フィルインできる爪か分からない」「初めてで不安」という層は
予約ボタンより相談ボタンを押します。完全予約制の個人サロンとは相性が良い導線です。

*実装:* `NEXT_PUBLIC_LINE_URL` は既に実装済み（SNSアイコンとして表示）。
加えて、CTAボタンとしても設置してください。

```
[ 空席確認・予約する ]  ← 主CTA（予約サイト）
[ LINEで相談する ]      ← 副CTA（迷っている層の受け皿）
```

**3. 料金を明示する【★★★】**

*理由:* 競合は 3,790円〜6,600円 と価格を明示しています。
検討フェーズのユーザーは価格が分からないサロンを候補から外します。
**4メニューが「料金確定後に掲載します」の状態は、比較検討で確実に負けます。**

**4. 「初回いくらか」を1行で示す【★★】**

*理由:* メニュー表を読ませる前に、総額の見当がつくと離脱が減ります。
ヒーロー直下に「初回◯◯円〜（オフ込み・所要約◯分）」の1行を置いてください。

**5. FAQをCTAの直前に置く【★★】**

*理由:* 予約直前の不安（キャンセル・所要時間・支払い）を解消してから
CTAを見せると押されやすくなります。現状はFAQセクションのあとに
アクセス→CTAの順で、間に情報が挟まっています。
**FAQ → CTA を隣接させてください。**

**6. モバイル固定バーの左ボタンを見直す【★★】**

現状は「初回クーポンを見る」／「空席確認・予約する」の2つ。
クーポンは予約への中間ステップとして妥当ですが、
**LINE相談に変えるほうが、迷っている層を拾えます**。A/Bで検証してください。

**7. 口コミを予約導線の近くに置く【★★】**

*理由:* 第三者評価は最後のひと押しになります。
実在の口コミが3件以上そろったら、CTAの直前に配置してください。

**8. スクロール連動CTAの出現タイミング【★】**

現状はモバイル固定バーが常時表示。
ファーストビューでは非表示にし、**スクロール開始後に出す**ほうが
ヒーローのCTAと競合せず、押し分けが明確になります。

**9. 「今日空いていますか」への即答【★】**

「当日予約OK」を訴求している以上、
**当日の空き状況をトップに出す**と強力です（手動更新でも可）。
GBPの投稿と連動させると効果が倍増します。

### 予約までの導線設計（理想形）

```
検索/マップ
  ↓
TOP（3秒で分かる: 場所・完全個室・フィルイン・駐車場・初回価格）
  ↓
不安解消（FAQ / 初めての方へ / 施術の流れ）
  ↓
判断材料（料金 / ギャラリー / 口コミ）
  ↓
┌─────────────┬─────────────┐
│ 予約する（決めた人）│ LINEで相談（迷っている人）│
└─────────────┴─────────────┘
```

**現在は右側の受け皿が存在しません。** 個人サロンで
「相談してから決めたい」層は無視できない比率です。
