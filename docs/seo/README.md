## いま最も重要な3つ

1. **予約URLを設定する** — 現状、予約CTAは全て機能していませんでした（今回は暫定でアクセスページへ誘導）。ここが埋まらない限り、集客施策は全て空振りになります。
2. **Googleビジネスプロフィールを開設して口コミを集める** — 自然検索の上位はポータルが占有しており、個人サロンが勝てる主戦場はマップ枠です。
3. **料金を確定して掲載する** — 競合は3,790〜6,600円と明示しており、価格不明は比較検討で確実に負けます。

## 調査の限界（明示）

- この環境からは `github.io` への外部アクセスがプロキシで遮断されているため、**公開URLの実表示・Lighthouse実測・Search Consoleの数値は確認していません**。診断はビルド成果物（公開ファイルと同一）の機械的解析に基づきます。
