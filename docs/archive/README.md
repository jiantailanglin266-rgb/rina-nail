## google-apps-script-booking/

Google Apps Script をバックエンドにした、サイト内完結型の予約システムです
（空き枠計算・重複防止・カレンダー登録・確認メール・予約変更/キャンセル・リマインド）。

**採用をやめた理由:** Googleカレンダーの「予約スケジュール」を使う方針に変更したためです。
予約スケジュールは無料で、Googleが予約ページ・確認メール・変更/キャンセルまで提供するため、
自前で同じ機能を持つ必要がなくなりました。セットアップも大幅に簡単です。

**もう一度使いたくなったら:** この `Code.gs` と、コミット `95680ed` にある
フロントエンド側の実装（ステップフォーム・空き枠計算・APIクライアント）が揃っています。

| 予約スケジュール（現行） | Apps Script（保管） |
|---|---|
| 設定はGoogleカレンダーの画面だけ | スクリプトの設置と公開が必要 |
| 予約フォームの項目はGoogleの範囲内 | 項目を自由に設計できる |
| メニューごとの所要時間は分けにくい | メニューごとに施術時間・料金を設定できる |
| 確認メールはGoogleの定型 | 文面を自由に作れる |
| 無料 | 無料（ただし設定の手間が大きい） |
