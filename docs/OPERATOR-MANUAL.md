# 予約の管理方法（スマートフォンだけで完結します）

**専用の管理画面はありません。** 使うのは次の2つだけです。

- **Googleカレンダー アプリ**
- **Gmail などのメールアプリ**

---

## 1. 予約を確認する

Googleカレンダーアプリを開きます。予約は次の形で入っています。

```
【ワンカラー】山田様
10:00 - 11:15
```

タイトルには**メニュー名とお名字だけ**を表示しています。
通知やロック画面に電話番号が出ないようにするためです。

## 2. 予約内容を詳しく見る

その予定をタップすると、詳細に次が書かれています。

```
予約ID: RN20260810ABC123
お客様名: 山田 花子（ヤマダ ハナコ）
電話番号: 09012345678
メール: hanako@example.com
メニュー: ワンカラー
オプション: 他店オフ
料金目安: ¥7,700
施術時間: 90分（準備・片付けを含め 120分）
オフ: 他店オフあり
来店: 初回
爪の状態: 欠けている
希望カラー: ベージュ系
連絡事項: 15分ほど遅れるかもしれません
```

## 3. お客様へ電話する

**予約通知メール**を開き、電話番号をタップすると発信できます。
カレンダーの詳細内の番号も、多くの端末でタップして発信できます。

## 4. お客様へメールを返信する

予約通知メールの「メールで返信」をタップすると、そのまま返信できます。

## 5. 予約の日時を変更する

**カレンダーの予定を、そのままドラッグして動かすだけです。**

1. 予定を長押し
2. 新しい時間へ移動
3. 保存

移動した時間は自動的に「予約不可」になり、
**元の時間は再び予約可能**になります。

> ⚠️ お客様への連絡は自動では行われません。
> 日時を動かしたら、メールか電話でお客様にお伝えください。
> （お客様ご自身がメールのリンクから変更した場合は、自動で通知されます）

## 6. 予約をキャンセルする

カレンダーの予定を**削除**します。
その時間は自動的に再び予約可能になります。

こちらもお客様への連絡は自動では行われません。ご一報ください。

## 7. 休みを登録する（予約を止める）

**カレンダーに予定を入れるだけです。** 予定の名前は何でも構いません。

```
例) 「休み」「お休み」「私用」「外出」
```

その時間帯は自動的に予約できなくなります。

### 1日まるごと休みにする

「終日」の予定にすれば、その日は1件も予約できなくなります。

### 一部の時間だけ止める

```
例) 14:00-16:00 「外出」
```

この時間に重なる枠が選べなくなります。
**準備・片付けの時間も考慮**されるので、
直前・直後の枠も自動的に押さえられます。

## 8. 営業時間を変えたいとき

営業時間は**2か所**を同じ値にする必要があります。
ご自身での変更が難しい場合は、制作者にご依頼ください。

- サイト側: `src/data/hours.ts`
- サーバー側: Apps Script の `CONFIG.businessHours`

一時的な変更であれば、**カレンダーに予定を入れるほうが簡単です**
（例: その日の16時以降を「終了」という予定で埋める）。

## 9. 予約通知メールを確認する

新しい予約が入ると、次の件名のメールが届きます。

```
【新規予約】2026年8月10日(月) 14:00 山田 花子様（ワンカラー）
```

内容には、お客様情報・メニュー・料金・連絡事項がすべて入っています。
**このメールを見れば、カレンダーを開かなくても内容が分かります。**

## 10. Googleアカウントを安全に守る

予約データとお客様の個人情報は、すべてこのGoogleアカウントの中にあります。

- **2段階認証を必ず有効にしてください**（設定 → セキュリティ）
- パスワードを他のサービスと使い回さない
- カレンダーとスプレッドシートを誰とも共有しない
- 端末を紛失した場合は、すぐにパスワードを変更する

## よくある質問

**Q. 予約が2件同時に入ることはありますか？**
ありません。予約が確定する瞬間にサーバー側で空き状況を確認し、
同時アクセスは1件ずつ順番に処理しています。
先に確定した方が優先され、後の方には「別の時間をお選びください」と表示されます。

**Q. お客様が自分でキャンセルできますか？**
できます。予約確認メールのリンクから変更・キャンセルできます。
その場合は運営者にも通知メールが届き、カレンダーからも自動で消えます。

**Q. カレンダーの予定を間違って消してしまいました。**
Googleカレンダーの「ゴミ箱」から30日以内であれば復元できます。
ただし、消えていた間にその時間へ別の予約が入る可能性があります。

**Q. 予約の履歴はどこに残りますか？**
「Rina nail 予約台帳」スプレッドシートに残ります。
普段見る必要はありませんが、確認したいときはここを開いてください。

**Q. メールが届かないというお客様がいます。**
迷惑メールフォルダをご確認いただいてください。
それでも届かない場合、カレンダーには予約が入っているので、
電話またはメールで直接ご連絡ください。
