# 写真マーキー用のフォルダ

**現在8枚が入っており、トップページで表示中です。**

**ここに写真を置くだけで、トップページに横スクロールの写真帯が表示されます。**
コードの変更は不要です。

- **4枚以上**で表示されます（少ないとすぐ同じ写真が戻ってきて不自然なため）
- 8〜16枚くらいがちょうどよく流れます
- 並び順は**ファイル名順**です（`01-`, `02-` と付けると順番を決められます）
- 対応形式: `.jpg` `.jpeg` `.png` `.webp` `.avif`

## 写真の選び方

- **横長（3:2 など）**がきれいに収まります。縦長でも中央が切り取られて表示されます
- 手元のアップなど、小さく表示されても何か分かるものが向いています
- 1枚あたり **300KB以下**を目安に。多く並ぶので、重いと表示が遅くなります

## 使いきれなかった写真の置き場所として

ギャラリーに載せきれなかった作例をここに入れると、サイト全体の情報量が増えます。
同じ写真をギャラリーと重複させても問題ありません。
