# 動画ファイルの置き場所

## 入り口の動画（トップページのファーストビュー直下）

- **ファイル名: `rina-nail-opening.mp4`**（この名前で置いてください）
- 形式: MP4（H.264）
- 音声: 無音でも構いません（サイト上では音を鳴らさずに再生します）

**このファイルが無い場合、動画セクションは表示されません。**
空の黒い枠が公開されないよう、ビルド時にファイルの有無を確認しています。

## 置いたあとの確認

`src/data/media.ts` の `width` / `height` を、**動画の実際の画素数**に合わせてください。
縦横比はここから自動で計算されます。

```ts
export const heroVideo: SiteVideo = {
  src: "/videos/rina-nail-opening.mp4",
  width: 864,
  height: 496,
};
```

この2つの値は、次の2か所で使われます。

1. **表示の縦横比** — 実際と違うと、動画の上下または左右が切り取られて表示されます
2. **パソコンでの表示幅の上限** — 実寸より大きく表示すると引き伸ばしになり、ぼやけます

## サイズの目安

- **画素数**: 横1280px前後あれば、パソコンでも十分に鮮明です
- **ファイル容量**: 小さいほど良く、**3MB以下**を目安にしてください
  （現在は 864×496 / 5秒 / 約1.7MB）

スマートフォンの通信量と表示速度に直結するため、
長さは10秒以内、必要に応じて書き出し設定でビットレートを下げてください。
