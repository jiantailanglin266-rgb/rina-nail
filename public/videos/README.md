# 動画ファイルの置き場所

## ブランド動画（トップページのファーストビュー直下）

- **ファイル名: `rina-nail-cm.mp4`**（この名前で置いてください）
- 形式: MP4（H.264）
- 音声: 無音でも構いません（サイト上では音を鳴らさずに再生します）

**このファイルが無い場合、動画セクションは表示されません。**
空の黒い枠が公開されないよう、ビルド時にファイルの有無を確認しています。

## 置いたあとの確認

`src/data/media.ts` の `aspectRatio` を、動画の実際の比率に合わせてください。

| 動画の向き | 設定値 |
|---|---|
| 横向き（16:9） | `"16 / 9"`（初期値） |
| 縦向き（9:16） | `"9 / 16"` |
| 正方形 | `"1 / 1"` |

ここが実際と違うと、動画の上下または左右が切り取られて表示されます。

## サイズの目安

10MB以下を推奨します。大きいと、スマートフォンの通信量と表示速度に影響します。
必要に応じて、書き出し設定でビットレートを下げてください。
