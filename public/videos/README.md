# 動画ファイルの置き場所

このサイトでは2本の動画を使います。**どちらも、無ければそのまま表示されない**だけで
壊れません（ビルド時にファイルの有無を確認しています）。

## 1. イントロ動画（アクセス直後に一度だけ全画面で流れる）

- **ファイル名: `rina-nail-opening.mp4`**
- 同じタブでは一度しか流れません。終わるかスキップで消えます
- 短いほど良いです（**5秒前後**推奨。閲覧の入り口を塞ぐため）

## 2. ブランド動画（トップページのファーストビュー直下のCM）

- **ファイル名: `rina-nail-cm.mp4`**
- ページ内で自動ループ再生します

共通: 形式は MP4（H.264）。音声は入っていても構いません
（サイト上では音を鳴らさずに再生します）。

## 置いたあとの確認

`src/data/media.ts` の `width` / `height` を、**動画の実際の画素数**に合わせてください。
縦横比はここから自動で計算されます。

```ts
export const heroVideo: SiteVideo = {
  src: "/videos/rina-nail-cm.mp4",
  width: 1728,
  height: 992,
};

export const introVideo: SiteVideo = {
  src: "/videos/rina-nail-opening.mp4",
  width: 864,
  height: 496,
};
```

この2つの値は、次の2か所で使われます。

1. **表示の縦横比** — 実際と違うと、動画の上下または左右が切り取られて表示されます
2. **パソコンでの表示幅の上限** — 実寸より大きく表示すると引き伸ばしになり、ぼやけます

## サイズの目安

- **画素数**: 横1280px前後あれば、パソコンでも十分に鮮明です
- **ファイル容量**: 小さいほど良く、**3MB以下**を目安にしてください
  （現在: イントロ 864×496 / 5秒 / 1.7MB、CM 1728×992 / 13秒 / 9.4MB）

スマートフォンの通信量と表示速度に直結するため、
長さは10秒以内、必要に応じて書き出し設定でビットレートを下げてください。
